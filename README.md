## نظرة عامة

نظام إدارة صيدليات احترافي كامل — نقطة بيع سريعة، إدارة أدوية ومخزون بمنهجية **FEFO**، وصفات طبية وتداخلات دوائية، عملاء وموردين وخزينة وموظفين وتقارير، مع دعم **فروع ومخازن متعددة** وطباعة حرارية 80mm وفواتير A4.

يعمل بقاعدة بيانات **SQLite مضمّنة داخل المشروع** — لا يحتاج أي خادم قواعد بيانات خارجي. عند أول تشغيل تُبنى القاعدة وتُزرع بالبيانات تلقائيًا (منتجات، مستخدمون، فروع، مخازن، كوبونات).

## التشغيل السريع

```bash
# 1) استنساخ المشروع
git clone https://github.com/engemadragabsh/pharmcy.git
cd pharmcy

# 2) تثبيت الحزم
npm install

# 3) التشغيل — لا إعداد يدوي إطلاقاً
npm run dev        # → http://localhost:3000
```

عند أول تشغيل يتم تلقائيًا: إنشاء `.env` بالمسار الصحيح → إنشاء قاعدة `db/custom.db` → إنشاء الجداول → بذر البيانات.

### التهيئة التلقائية لقاعدة البيانات (Idempotent)

| القاعدة | الجداول | البيانات | الإجراء |
| :---: | :---: | :---: | --- |
| مفقودة | — | — | إنشاء القاعدة + الجداول + البذر |
| موجودة | مفقودة | — | إنشاء الجداول + البذر |
| موجودة | موجودة | فارغة | بذر فقط |
| موجودة | موجودة | بها بيانات | **لا يفعل شيئاً** |

- المنسّق: `scripts/setup-db.ts` — البذر: `prisma/seed.ts` (upsert + حماية تزامن)
- يعمل قبل `dev`/`start` وعند إقلاع السيرفر (`instrumentation.ts`)

### الإنتاج

```bash
npm run build
npm start          # standalone server على المنفذ 3000
```

راجع [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) — يشمل VPS/Docker والنسخ الاحتياطي وقائمة فحص الإنتاج.

## الحسابات الافتراضية

| الدور | المستخدم | كلمة المرور | PIN |
| --- | --- | --- | --- |
| مدير النظام | `admin` | `Admin@123` | — |
| صيدلي | `pharmacist` | `Pharma@123` | — |
| كاشير | `cashier` | `Cashier@123` | `1234` |
| محاسب | `accountant` | `Account@123` | — |
| مسؤول مخزون | `inventory` | `Inv@123` | — |

كوبونات تجريبية: `WELCOME10` (خصم 10%) و `PHARMA25` (خصم 25 ج.م).

> **مهم للإنتاج:** من شاشة الموظفين غيّر كلمات المرور الافتراضية فوراً، أو عطّل الحسابات غير المستخدمة. اسم المستخدم غير حساس لحالة الأحرف، أما كلمة المرور فحساسة لها.

## الأمان

- bcrypt لتشفير كلمات المرور · JWT HS256 (jose) مع توكن تجديد
- Rate Limiting على تسجيل الدخول (10 محاولات/دقيقة)
- حرس أدوار على كل نقطة نهاية + مصفوفة صلاحيات في الواجهة
- Prisma Parameterized Queries (منع SQL Injection) · Audit Log لكل عملية حساسة
- FEFO ذري داخل `$transaction` — لا بيع من تشغيلة منتهية
